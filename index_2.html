🔑 Connect to GitHub

A GitHub token is needed to load and save shared data. Each team member enters their token once — it stays in their browser.

  1. Go to github.com/settings/tokens (opens in new tab)
  2. Set Note: PA Tracker
  3. Check ✓ repo
  4. Click Generate token and paste below

Your token is only saved in your browser — never sent anywhere except GitHub.
